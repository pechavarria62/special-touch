# special-touch

A TypeScript project.

## Requirements

- Node.js 20+
- npm

## Getting started

```bash
npm install
npm run dev      # run with hot reload
npm run build    # compile to dist/
npm start        # run the compiled build
```

## Project structure

```
special-touch/
├── src/
│   └── index.ts     # entry point
├── package.json
├── tsconfig.json
└── README.md
```
